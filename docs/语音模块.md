# 语音（声音）模块 · 完整使用说明

> 这份文档讲清楚：**她能发出哪些声音、怎么换、每种方式怎么配、坏了怎么查**。
> 对应代码：`lib/voice.js`（合成与格式转换）、`lib/breeze-voice.js`（云端音色）。

---

## 一、三种声音，三选一

在「设置 → 养鱼 · QQ → 声音 → 用谁的声音」里选：

| 选项 | 是什么 | 要不要配 | 花不花钱 |
| --- | --- | --- | --- |
| **大肥鱼的音色** | BreezeBlue 云端合成，自带两个「大肥鱼」 | 要填 API Key | 按字数计费 |
| **电脑自带的** | Windows 系统 TTS | 不用配，装好就能用 | 免费 |
| **我自己的录音** | 你自己导入的一段音频 | 要导入文件 | 免费 |

**默认是「电脑自带的」**——不配任何东西就能出声。

---

## 二、自带的两个大肥鱼音色

| 音色 | Voice ID | 听感 |
| --- | --- | --- |
| 大肥鱼（机灵版） | `voc_u3nxkd5578wc` | 清亮、机灵，想到好主意会雀跃起来 |
| 大肥鱼（迷糊版） | `voc_8yud7hz7c9q2` | 轻软、有点小迷糊，走神后会回神 |

> 默认选「机灵版」。点一下面板上的另一个名字就换过去。

### ⚠️ 必须先知道的一件事

这两个音色**公开可以试听**，但用 API 合成**仍然需要你自己的 API Key**。
Voice ID 只说明「用哪个声音」，不包含任何授权或额度。

没有 Key 会怎样？
**会自动退回「电脑自带的声音」，她不会哑掉。** 面板上会写清楚原因。

## 三、第一步：拿 API Key（只做一次）

1. 打开 <https://breezeblue.ai/app/developer/api-keys>
2. 注册 / 登录（Free 套餐月费 $0，每天可领 400 credits）
3. 建一个 API Key，复制下来（`sk_` 开头）
4. 回到「设置 → 养鱼 · QQ → 声音」，选「大肥鱼的音色」
5. 把 Key 粘进输入框

**Key 存在哪**：只管存在你本机的 `~/.dsh/whale-channels/channels/qq.json` 里，
不会上传、不会进仓库、日志和错误消息里也会被替换成 `sk_***`。

---

## 四、花多少钱（重要）

按 BreezeBlue 官方口径（2026-10）：

- **1 credit = 10 个计费字符**，一个汉字算 **2 个字符**
- 一条 **50 字**的话 ≈ **10 credits**
- 充值单价 **$3 / 10,000 credits**

| 用量 | Credits | 约合美元 |
| --- | --- | --- |
| 一条 50 字回复 | 10 | $0.003 |
| 100 条 × 50 字 | 1,000 | $0.30 |
| 每天 100 条，连续 30 天 | 30,000 | $9.00 |

Free 套餐每天领 400 credits ≈ **40 条 50 字的语音**。

### 所以默认就带了两道刹车

| 设置 | 默认 | 作用 |
| --- | --- | --- |
| `voice.breeze.maxChars` | 120 | 单条最多念多少字，超了就退回文字 |
| `voice.breeze.dailyMax` | 40 | 一天最多合成几条，超了就退回文字 |

**这两道刹车在「声音」面板里能改。** 建议别关掉——
不然她一口气说一百句，额度瞬间就没了。

## 五、想用别的音色（音色库里的任意一个）

面板下方「想换别的音色」：

1. 去 <https://breezeblue.ai/zh/voice-library> 挑一个
2. 打开那个音色的页面，URL 里最后一段就是它的 ID，形如 `voc_xxxxxxxx`
3. 粘进「Voice ID」框，随便起个名
4. 点「添加」

加过之后它会出现在上面的按钮排里，点一下就能切过去。

**可以有任意多个**，自带那两个永远在最前面（不会被删掉）。

---

## 六、用自己录的一段音频

面板里选「我自己的录音」，然后在输入框填**本机音频文件的完整路径**，点「导入」。

支持的格式：`.wav` `.mp3` `.m4a` `.aac` `.ogg` `.flac` `.amr`

导入后插件会把它复制到 `~/.dsh/whale-work/` 下面托管，
原文件删了也不影响。

> **这不是 TTS**。它是「每次都用同一段音频」——
> 适合「她固定说某一句」或者「你给她录了一句口癖」。
> 想让她按文字念出来，用前两种。

## 七、技术细节（想改代码的人看）

### 7.1 调用链

```
reply-sender.tick()
  → compose.materializeMessage()          plan.kind === 'voice'
    → voice.makeVoice()                     ← 三种引擎在这里分流
       ├─ engine='breeze' → breeze-voice.synthBreeze()   → 返回 mp3 Buffer
       ├─ engine='tts'    → voice.synthWav()              → PowerShell 念成 wav
       └─ engine='file'   → 直接用 customFile
    → voice.toQqAudio()                     wav/mp3 → amr（QQ 要 amr）
  → onebot.sendPrivate / sendGroup   [CQ:record,file=...]
```

### 7.2 BreezeBlue 请求长什么样

```http
POST https://api.breezeblue.ai/v1/audio/speech
Authorization: Bearer sk_xxxxxxxx
Content-Type: application/json

{
  "input": "呜哇，被你发现啦！",
  "voice": "voc_u3nxkd5578wc",
  "response_format": "mp3"
}
```

返回二进制音频（mp3）。

**注意**：`voice` 字段就是 Voice ID。`model` 留空表示用服务端默认模型；
想指定就在配置里填 `voice.breeze.model`。

### 7.3 用量是怎么算的

`~/.dsh/whale-work/breeze-usage.json`：

```json
{ "day": "2026-11-08", "count": 12, "chars": 586 }
```

- `day` 变了就自动归零（按本地日期）
- 每次成功合成 +1
- `dailyMax` 和它比，超了直接返回错误（**不扣费**，因为根本没发请求）

### 7.4 失败时会发生什么

| 情况 | 行为 |
| --- | --- |
| 没填 Key | 退回系统 TTS，`breezeError` 记原因 |
| Key 不对（401） | 退回系统 TTS，提示「Key 不对或过期」 |
| 额度用完（402） | 退回系统 TTS，提示「去后台充值」 |
| 请求太快（429） | 退回系统 TTS，提示「稍等」 |
| 网络不通 | 退回系统 TTS |
| 文字太长 | 退回系统 TTS（超过 maxChars） |
| 今天超条数 | 退回系统 TTS |

**核心原则：任何情况下都不能让她哑掉。** 云端不行就本地念。

### 7.5 格式转换

QQ 的语音消息要 **amr**。所以：

1. 先找本机的 ffmpeg（`voice.findFfmpeg()`）
2. 有就转 amr
3. 没有就**原样把 mp3/wav 交给 NapCat**，让它自己转
   （NapCat 自带 ffmpeg）

转成功才删中间文件；没转成功**留着**，因为还要靠它发。

## 八、坏了怎么查

### 问题：选了「大肥鱼的音色」但听起来还是电脑声音

看「声音」面板那一行的状态：

- **「✗ 还没填 —— 现在会退回电脑自带的声音」** → Key 没填
- **「✓ 已填」** 但还是电脑声音 → 看下面

去 `~/.dsh/whale-work/breeze-usage.json` 看今天用了几条。
如果 `count` 到了 `dailyMax`，那就是被刹车拦了。

### 问题：语音发不出去

先确认**文字**能不能发。文字能发、语音不能，问题在格式转换：

1. 找 ffmpeg：配置里 `voice.ffmpeg` 填一个路径
2. 或者确认 NapCat 的 ffmpeg 在不在（它自带的）

### 问题：报 401

Key 不对或过期。去后台重新生成一个，粘贴进来覆盖。

### 问题：报 402

额度用完了。去 <https://breezeblue.ai/pricing> 充值，或者把
`voice.breeze.dailyMax` 调小一点先用着。

### 想看实际请求

插件**不会**把 Key 打进日志。想确认请求发了没有，
看 `~/.dsh/whale-work/breeze-usage.json` 的 `count` 有没有涨。

---

## 九、关掉语音

三种方式，从轻到重：

1. **声音面板** → 选「电脑自带的」（省钱，还能出声）
2. **`voice.enabled = false`** → 完全不出声，只发文字
3. **`voice.breeze.enabled = false`** → 关掉云端，其他不变

---

## 十、和 B 站那边共用吗

**不共用。** 语音配置是 QQ 通道自己的（在 `qq.json` 里），
B 站那边有它自己的一套。

想两边一样，就在两边分别配一次。API Key 可以共用同一个。
