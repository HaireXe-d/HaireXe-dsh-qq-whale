# 语音（声音）模块 · 完整使用说明

> 这份文档讲清楚：**她能发出哪些声音、怎么换、坏了怎么查**。
> 对应代码：`lib/voice.js`。

---

## 一、自带两种大肥鱼音色（默认，不花钱）

装好插件就有，**不用配任何东西、不用填 Key、不花钱**。

在「设置 → 养鱼 · QQ → 声音」里点按钮切换：

| 音色 | 音调 | 语速 | 听感 |
| --- | --- | --- | --- |
| **大肥鱼 · 机灵版** | +18% | +2 | 精神、爱抢话、雀跃 |
| **大肥鱼 · 迷糊版** | -12% | -3 | 软、慢、有点走神 |

默认是**机灵版**。

### 还能自己微调音调

面板上有「再调一下音调」的滑杆（-50 ~ +50）：

- 往右 → 更尖、更精神
- 往左 → 更低沉、更软
- 0 = 保持预设原样

调完点「保存」，再点「试听一句」听听。

## 二、原理（为什么不用配 Key 也能变声）

### 2.1 用的是电脑自带的朗读声音

Windows 自带中文 TTS（`Microsoft Huihui Desktop`）。
插件拿它念你要说的话，然后用 **SSML** 改音调和语速。

### 2.2 一个坑：`SetPitch()` 不存在

`.NET 4.x` 的 `System.Speech.Synthesis.SpeechSynthesizer` **没有 `SetPitch()`**——
只有 .NET 5+ 才有。实测调用直接报：

```
Method invocation failed because [System.Speech.Synthesis.SpeechSynthesizer]
does not contain a method named 'SetPitch'.
```

Windows 自带的 PowerShell 5.1 全是 4.x，所以这条路走不通。

### 2.3 解法：走 SSML

`SpeakSsml()` 是有的，而 SSML 里的 `<prosody>` 支持 `pitch` 和 `rate`：

```xml
<speak version="1.0" xmlns="http://www.w3.org/2001/10/synthesis" xml:lang="zh-CN">
  <voice name="Microsoft Huihui Desktop">
    <prosody rate="+10%" pitch="+18%" volume="100">呜哇，被你发现啦！</prosody>
  </voice>
</speak>
```

所以 `synthWav()` 的逻辑是：

```
pitch === 0  → 走原来的 $s.Speak(text)（不加 SSML，行为完全不变）
pitch !== 0  → 走 $s.SpeakSsml(ssml)
```

**这个设计保证**：老配置（`engine='tts'`、没设 pitch）的行为一点没变。

### 2.4 参数换算

| 我们的配置 | SSML 里的值 | 说明 |
| --- | --- | --- |
| `rate: -10..10` | `-50%..+50%` | ×5，SAPI 的档位换算成百分比 |
| `pitch: -50..50` | `-50%..+50%` | 直接当百分比用 |

### 2.5 文字里的特殊字符必须转义

SSML 是 XML，`< > & " '` 都得转义。代码里做了：

```js
const escXml = (s) => String(s ?? '')
  .replace(/&/g, '&amp;')
  .replace(/</g, '&lt;')
  .replace(/>/g, '&gt;')
  .replace(/"/g, '&quot;')
  .replace(/'/g, '&apos;')
```

不转义的话，她要是说一句「他说"你好" <然后> 笑了」，
SSML 直接解析失败，语音就发不出来。

## 三、实测效果

同一句话「今天天气真好呀，我们出去玩吧」：

```
机灵版  260 KB   ← 语速快
迷糊版  557 KB   ← 语速慢（两倍长）
```

音调 +30 vs -30 → **波形不同**（逐字节比对过）。

## 四、想用别的声音

面板下方的「不用大肥鱼的话」：

| 选项 | 是什么 | 要配什么 |
| --- | --- | --- |
| 电脑原声 | 系统 TTS 原始声音，从已装的音色里挑 | 不用配 |
| 我的录音 | 你导入的一段音频 | 导入文件 |

### 4.1 换成别的系统音色

如果这台 Windows 装了别的中文 TTS（比如微软云希、晓晓），
在「电脑原声」模式下就能在下拉框里选到。

**想让预设也用别的音色**：改 `~/.dsh/whale-channels/channels/qq.json`：

```json
"voice": {
  "preset": "clever",
  "voice": "你想用的那个音色名"
}
```

音调/语速照样生效。

### 4.2 用自己录的一段音频

填**本机音频文件的完整路径**，点「导入」。

支持：`.wav` `.mp3` `.m4a` `.aac` `.ogg` `.flac` `.amr`

导入后复制到 `~/.dsh/whale-work/` 托管，原文件删了也不影响。

> **这不是 TTS**。它是「每次都用同一段音频」——
> 适合「她固定说某一句」或者「你给她录了一句口癖」。
> 想让她按文字念出来，用前两种。

## 五、调用链

```
reply-sender.tick()
  → compose.materializeMessage()          plan.kind === 'voice'
    → voice.makeVoice()                     ← 三种引擎在这里分流
       ├─ engine='preset' → synthWav(pitch=预设值)   ← 自带大肥鱼（默认）
       ├─ engine='tts'    → synthWav(pitch=配置值)   ← 电脑原声
       └─ engine='file'   → 直接用 customFile
    → voice.toQqAudio()                     wav/mp3 → amr（QQ 要 amr）
  → onebot.sendPrivate / sendGroup   [CQ:record,file=...]
```

### 5.1 三种引擎

| 引擎 | 说明 | 默认 |
| --- | --- | --- |
| `preset` | 自带大肥鱼（系统 TTS + 音调） | ✅ |
| `tts` | 电脑原声，可自选音色 | |
| `file` | 用自己导入的音频 | |

### 5.2 格式转换

QQ 的语音消息要 **amr**。所以：

1. 先找本机 ffmpeg（`voice.findFfmpeg()`）
2. 有就转 amr
3. 没有就**原样把 wav/mp3 交给 NapCat**，让它自己转（NapCat 自带 ffmpeg）

转成功才删中间文件；没转成功**留着**，因为还要靠它发。

## 六、坏了怎么查

### 听起来还是电脑原声，不像大肥鱼

**原因**：`engine` 还是 `tts`（老配置没迁移过来）。

**怎么办**：声音面板里点「大肥鱼 · 机灵版」或「大肥鱼 · 迷糊版」，保存。

### 声音太尖 / 太闷

调「再调一下音调」滑杆。往左变软，往右变尖。

### 语音发不出去

先确认**文字**能不能发。文字能发、语音不能 → 问题在格式转换：

1. 配置里 `voice.ffmpeg` 填一个 ffmpeg 路径
2. 或者确认 NapCat 的 ffmpeg 在不在（它自带的）

### 提示「这台机器没检测到朗读声音」

说明这台 Windows 没装中文 TTS。
去「设置 → 时间和语言 → 语音」加一个中文语音包，或者用「我的录音」。

### 她说的内容有引号、尖括号，语音发不出来

那是 SSML 转义的问题（见 2.5）。代码里已经处理了，
如果还出问题，把那段文字发我。

## 七、关掉语音

| 方式 | 效果 |
| --- | --- |
| 面板切到「电脑原声」 | 不用预设，但还能出声 |
| `voice.enabled = false` | 完全不出声，只发文字 |

## 八、和 B 站那边共用吗

**不共用。** 语音配置是 QQ 通道自己的（在 `qq.json` 里），
B 站那边有它自己的一套。

想两边一样，就在两边分别配一次。
