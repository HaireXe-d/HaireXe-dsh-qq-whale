# 语音（声音）模块 · 完整使用说明

> 这份文档讲清楚：**她能发出哪些声音、怎么换、每种方式怎么配、坏了怎么查**。
> 对应代码：`lib/voice.js`（合成与格式转换）、`lib/breeze-voice.js`（云端音色）。

---

## 一、四种声音，默认不用花钱

在「设置 → 养鱼 · QQ → 声音 → 用谁的声音」里选：

| 选项 | 是什么 | 要不要配 | 花不花钱 |
| --- | --- | --- | --- |
| **大肥鱼（自带·免费）** | 用电脑自带朗读声音 + 音调改造 | **不用配，装好就能用** | **免费** |
| 电脑原声 | Windows 系统 TTS，原始声音 | 不用配 | 免费 |
| 我自己的录音 | 你导入的一段音频 | 要导入文件 | 免费 |
| 云端真声（要钱） | BreezeBlue 云端真声优 | 要自己的 API Key | 按字数计费 |

**默认就是第一个「大肥鱼（自带·免费）」**——装好、扫码、就能听到她说话，一分钱不花。

## 二、自带的两个大肥鱼音色（免费，重点）

这是**用 Windows 自带的中文音色（Huihui）+ SSML 调音调/语速**做出来的：

| 预设 | 参数 | 听感 |
| --- | --- | --- |
| **机灵版** | 音调 +18%，语速 +2 | 精神、爱抢话、雀跃 |
| **迷糊版** | 音调 -12%，语速 -3 | 软、慢、有点走神 |

点面板上的按钮切换，切完点「保存」再点「试听一句」。

### 它和真声优差在哪

| | 自带预设 | 云端真声 |
| --- | --- | --- |
| 能说任意文字 | ✅ | ✅ |
| 像大肥鱼本人 | ⚠️ 相似但不完全 | ✅ 就是 |
| 要花钱 | ❌ 不要 | ✅ 要 |
| 要 Key | ❌ 不要 | ✅ 要 |
| 离线可用 | ✅ | ❌ 要联网 |

**一句话**：自带预设是「用电脑的声音模仿出那个性格」，不是声优本人。
想要一模一样就去用第四个（云端真声）。

### 还能自己调音调

面板上有「再调一下音调」的滑杆（-50 ~ +50）：

- 往右 → 更尖、更精神
- 往左 → 更低沉、更软
- 0 = 保持预设原样

调完记得保存 + 试听。

## 三、技术原理（自带预设为什么能改音调）

### 3.1 一个坑：`SetPitch()` 不存在

`.NET 4.x` 的 `System.Speech.Synthesis.SpeechSynthesizer` **没有 `SetPitch()` 方法**——
只有 .NET 5+ 才有。实测调用会报：

```
Method invocation failed because [System.Speech.Synthesis.SpeechSynthesizer]
does not contain a method named 'SetPitch'.
```

（这台机器就是 4.x，Windows 自带的 PowerShell 5.1 都是这个版本。）

### 3.2 解法：走 SSML

`SpeakSsml()` 是有的，而 SSML 里的 `<prosody>` 支持 `pitch` 和 `rate`：

```xml
<speak version="1.0" xmlns="http://www.w3.org/2001/10/synthesis" xml:lang="zh-CN">
  <voice name="Microsoft Huihui Desktop">
    <prosody rate="+10%" pitch="+18%" volume="100">呜哇，被你发现啦！</prosody>
  </voice>
</speak>
```

所以 `synthWav()` 的逻辑是：

```
pitch === 0  → 走原来的 $s.Speak(text)（不加 SSML，行为完全不变）
pitch !== 0  → 走 $s.SpeakSsml(ssml)
```

**这个设计保证**：老配置（`engine='tts'`、没设 pitch）的行为一点没变。

### 3.3 参数换算

| 我们的配置 | SSML 里的值 | 说明 |
| --- | --- | --- |
| `rate: -10..10` | `-50%..+50%` | ×5，SAPI 的档位换算成百分比 |
| `pitch: -50..50` | `-50%..+50%` | 直接当百分比用 |

### 3.4 文字里的特殊字符

SSML 是 XML，`< > & " '` 必须转义。代码里做了：

```js
const escXml = (s) => String(s ?? '')
  .replace(/&/g, '&amp;')
  .replace(/</g, '&lt;')
  .replace(/>/g, '&gt;')
  .replace(/"/g, '&quot;')
  .replace(/'/g, '&apos;')
```

不转义的话，她要是说一句「他说"你好" <然后> 笑了」，SSML 直接解析失败，语音就发不出来。

## 四、换别的系统音色（如果你装了）

如果你的 Windows 装了别的中文 TTS（比如微软云希、晓晓），
在「电脑原声」模式下就能选到它们。

**想让预设用别的音色**：改 `~/.dsh/whale-channels/channels/qq.json` 里的：

```json
"voice": {
  "preset": "clever",
  "voice": "你想用的那个音色名"
}
```

音调/语速照样生效。

怎么查本机有哪些音色？插件启动时会自动列出来，设置页的下拉框里就能看到。

## 五、云端真声优（要花钱，可跳过）

如果你想要**真正的大肥鱼声优**（不是模仿），用这个。

### 5.1 两个自带音色

| 音色 | Voice ID | 听感 |
| --- | --- | --- |
| 大肥鱼（机灵版） | `voc_u3nxkd5578wc` | 清亮、机灵 |
| 大肥鱼（迷糊版） | `voc_8yud7hz7c9q2` | 轻软、小迷糊 |

> ⚠️ 这两个音色公开可听，但**用 API 合成要你自己的 Key**。
> Voice ID 只是「用哪个声音」，不含任何授权。

### 5.2 拿 Key + 花钱

1. <https://breezeblue.ai/app/developer/api-keys> → 建一个
2. 粘到面板里
3. 计费：1 credit = 10 计费字符，汉字每字算 2；$3 / 10,000 credits
   一条 50 字 ≈ 10 credits；Free 套餐每天 400 ≈ 40 条

### 5.3 两道刹车

| 设置 | 默认 | 作用 |
| --- | --- | --- |
| `voice.breeze.maxChars` | 120 | 单条最多念多少字 |
| `voice.breeze.dailyMax` | 40 | 一天最多合成几条 |

超了**不发请求直接退回**，不扣费。

### 5.4 云端失败会怎样

| 情况 | 行为 |
| --- | --- |
| 没填 Key | 退回自带预设 |
| Key 不对（401） | 退回，提示「Key 不对或过期」 |
| 额度用完（402） | 退回，提示「去后台充值」 |
| 请求太快（429） | 退回 |
| 网络不通 / 太长 / 超条数 | 退回 |

**核心原则：任何情况下都不能让她哑掉。**

## 六、用自己录的一段音频

面板里选「我自己的录音」，填**本机音频文件的完整路径**，点「导入」。

支持：`.wav` `.mp3` `.m4a` `.aac` `.ogg` `.flac` `.amr`

导入后复制到 `~/.dsh/whale-work/` 托管，原文件删了也不影响。

> **这不是 TTS**。它是「每次都用同一段音频」——
> 适合「她固定说某一句」或者「你给她录了一句口癖」。
> 想让她按文字念出来，用前面那几种。

## 七、调用链

```
reply-sender.tick()
  → compose.materializeMessage()          plan.kind === 'voice'
    → voice.makeVoice()                     ← 四种引擎在这里分流
       ├─ engine='preset' → synthWav(pitch=预设值)   ← 自带大肥鱼（免费）
       ├─ engine='tts'    → synthWav(pitch=配置值)   ← 电脑原声
       ├─ engine='breeze' → breeze-voice.synthBreeze() → mp3
       └─ engine='file'   → 直接用 customFile
    → voice.toQqAudio()                     wav/mp3 → amr（QQ 要 amr）
  → onebot.sendPrivate / sendGroup   [CQ:record,file=...]
```

### 7.1 格式转换

QQ 的语音消息要 **amr**。所以：

1. 先找本机 ffmpeg（`voice.findFfmpeg()`）
2. 有就转 amr
3. 没有就**原样把 wav/mp3 交给 NapCat**，让它自己转（NapCat 自带 ffmpeg）

转成功才删中间文件；没转成功**留着**，因为还要靠它发。

### 7.2 云端请求长什么样

```http
POST https://api.breezeblue.ai/v1/audio/speech
Authorization: Bearer sk_xxxxxxxx
Content-Type: application/json

{
  "input": "呜哇，被你发现啦！",
  "voice": "voc_u3nxkd5578wc",
  "response_format": "mp3"
}
```

### 7.3 用量记在哪

`~/.dsh/whale-work/breeze-usage.json`：

```json
{ "day": "2026-11-08", "count": 12, "chars": 586 }
```

`day` 变了自动归零。

## 八、坏了怎么查

### 选了自带预设，但听起来还是电脑原声

**现象**：能说话，但不像大肥鱼。

**原因**：`engine` 还是 `tts`（老配置没迁移过来）。

**怎么办**：声音面板里点「大肥鱼（自带·免费）」，保存。

### 语音发不出去

先确认**文字**能不能发。文字能发、语音不能 → 问题在格式转换：

1. 配置里 `voice.ffmpeg` 填一个 ffmpeg 路径
2. 或者确认 NapCat 的 ffmpeg 在不在（它自带的）

### 声音太尖 / 太闷

调「再调一下音调」的滑杆。往左变软，往右变尖。

### 云端报 401 / 402

- 401 → Key 不对或过期，去后台重生成
- 402 → 额度用完了，充值或调小 `dailyMax`

### 想看实际发了没有

插件**不会**把 Key 打进日志。想确认请求发了没有，
看 `~/.dsh/whale-work/breeze-usage.json` 的 `count` 有没有涨。

## 九、关掉语音

| 方式 | 效果 |
| --- | --- |
| 面板选「电脑原声」（还可以再选个别的音色） | 不用预设，但还能出声 |
| `voice.enabled = false` | 完全不出声，只发文字 |
| `voice.breeze.enabled = false` | 关掉云端，其他不变 |

## 十、和 B 站那边共用吗

**不共用。** 语音配置是 QQ 通道自己的（在 `qq.json` 里），
B 站那边有它自己的一套。

想两边一样，就在两边分别配一次。API Key 可以共用同一个。
